**[zhoukai.space](https://zhoukai.space)**

Kai Zhou's personal website.

Math is rendered with KaTeX at build time. Use `$...$` for inline formulas and
`$$...$$` on separate lines for display formulas. Keep commands and source code
in backticks or fenced code blocks; they are not parsed as math. Escape literal
dollar signs with `\$` in prose. Wide display formulas scroll horizontally on
narrow screens, and RSS feeds include MathML.
